# kaled-fighter

Jogo de página única (`index.html`) publicado via GitHub Pages.

## Regra de git (definida pelo dono do repo)

- **Trabalhe sempre direto na `main`.** Commit e push vão para `main`.
- **Nunca crie branches de feature** nem abra pull requests para mudanças
  neste repo — o deploy do GitHub Pages sai da `main`, então qualquer
  alteração precisa aterrissar lá para ir ao ar.
